Le projet fonctionnait avant la tentative de migration PostgreSQL.

Objectif : restaurer complètement SQLite et corriger Prisma 7.

Actions à effectuer :

1. Lire :

* backend/prisma/schema.prisma
* backend/prisma.config.ts
* backend/.env

2. Restaurer SQLite.

Le fichier schema.prisma doit utiliser :

```prisma
generator client {
  provider = "prisma-client-js"
}

datasource db {
  provider = "sqlite"
}
```

IMPORTANT :
Ne pas utiliser :

```prisma
url = env("DATABASE_URL")
```

car Prisma 7 retourne l'erreur P1012.

3. Vérifier prisma.config.ts.

Le fichier doit contenir :

```ts
import { defineConfig, env } from "prisma/config";

export default defineConfig({
  schema: "prisma/schema.prisma",
  datasource: {
    url: env("DATABASE_URL"),
  },
});
```

4. Vérifier backend/.env :

```env
PORT=5000
CLIENT_URL=http://localhost:3000
DATABASE_URL=file:./dev.db
JWT_SECRET=dev_secret_nika_hotel_2026
```
