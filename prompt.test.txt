Améliore le module QR Codes et notifications admin du projet NIKA HOTEL.

CONTEXTE :
Le QR room service fonctionne maintenant et ouvre bien :
https://nika-hotel-premium.vercel.app/room-service/{roomNumber}

Mais il faut améliorer l’administration.

==================================================
1. PAGE /admin/qrcodes
==================================================

À ajouter :
- Bouton global en haut : “Tout imprimer”
- Ce bouton doit imprimer tous les QR codes de toutes les chambres en une seule page.
- La page d’impression doit être propre et professionnelle :
  - logo NIKA HOTEL
  - titre : QR Codes Room Service
  - une carte par chambre
  - Chambre 101, 102, 103, etc.
  - type de chambre
  - QR code grand format
  - URL sous le QR
  - consigne : “Scannez pour commander depuis votre chambre”
- Format impression A4.
- Mise en page responsive pour impression.
- Éviter les coupures moches entre cartes avec page-break-inside: avoid.
- Garder les boutons existants :
  - Télécharger
  - Imprimer
  - Copier URL
  - Tester
- Si possible, ajouter “Tout télécharger” en option, mais priorité à “Tout imprimer”.

IMPORTANT :
Les QR doivent toujours pointer vers :
https://nika-hotel-premium.vercel.app/room-service/{roomNumber}

Ne jamais utiliser localhost en production.

==================================================
2. NOTIFICATIONS ADMIN GLOBALES
==================================================

Problème actuel :
Les notifications room service ne doivent pas fonctionner uniquement sur /admin/room-service.
Elles doivent fonctionner dans tout l’espace admin.

Objectif :
Créer un vrai système de notification admin global.

À faire :
- Créer un composant global :
frontend/src/components/admin/AdminNotificationProvider.tsx

- L’intégrer dans :
frontend/src/app/admin/layout.tsx

Le provider doit :
1. Surveiller les nouvelles commandes room service.
2. Fonctionner sur toutes les pages admin :
   - /admin/dashboard
   - /admin/reservations
   - /admin/rooms
   - /admin/room-service
   - /admin/qrcodes
   - /admin/messages
   - /admin/gallery

3. Afficher un bouton global :
   “Activer les notifications”
   car les navigateurs bloquent le son sans interaction utilisateur.

4. Quand une nouvelle commande arrive :
   - jouer un son
   - afficher toast : “Nouvelle commande — Chambre 102”
   - vibrer si compatible :
     navigator.vibrate([200, 100, 200])
   - afficher un badge compteur dans la sidebar à côté de “Room Service”
   - ne pas rejouer le son pour les anciennes commandes déjà vues

5. Le système doit rester actif tant que l’admin navigue dans l’espace admin.

6. Ne pas faire clignoter les pages.
7. Ne pas utiliser window.location.reload().
8. Ne pas utiliser router.refresh() en boucle.
9. Polling silencieux toutes les 5 secondes si WebSocket absent.
10. Si WebSocket/socket.io existe déjà dans le backend, utiliser WebSocket pour du vrai temps réel.
