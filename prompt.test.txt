=Migrer NIKA HOTEL de SQLite vers PostgreSQL pour production Render.

Objectif :
Utiliser une vraie base PostgreSQL persistante pour :
- réservations
- chambres
- messages
- room service
- historique commandes
- admin

À faire :

1. Modifier backend/prisma/schema.prisma

Remplacer :

datasource db {
  provider = "sqlite"
}

par :

datasource db {
  provider = "postgresql"
  url      = env("DATABASE_URL")
}

2. Vérifier que tous les modèles Prisma sont compatibles PostgreSQL.

3. Ne pas supprimer les modèles existants.

4. Mettre à jour backend/.env.example :

DATABASE_URL="postgresql://USER:PASSWORD@HOST:PORT/DATABASE?schema=public"

5. Adapter si nécessaire les services backend.

6. Tester localement avec :
npx prisma generate
npx prisma db push
npm run build

7. Ne pas toucher au frontend sauf si nécessaire.

Résultat attendu :
- build backend OK
- Prisma PostgreSQL OK
- les routes API continuent à fonctionner
- admin account seeded
- aucune erreur SQLite
