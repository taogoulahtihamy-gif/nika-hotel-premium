RÈGLES MOBILE OBLIGATOIRES :

1. Ajouter globalement :
html, body {
  overflow-x: hidden;
  width: 100%;
}

* {
  box-sizing: border-box;
}

2. Tous les containers doivent respecter :
width: 100%;
max-width: 100%;
padding-left/right: 20px maximum sur mobile.

3. Navbar mobile :
Sur écran <= 768px :
- hauteur max 72px
- logo rond NH visible
- texte "NIKA HOTEL" réduit ou caché si manque de place
- bouton Réserver compact
- bouton WhatsApp rond compact
- burger compact
- aucun débordement horizontal

4. Menu mobile :
- position fixed
- top: 0
- right: 0
- width: min(82vw, 340px)
- height: 100vh
- padding-top: 110px
- fond bleu nuit opaque
- z-index très élevé
- liens verticaux bien espacés
- fermer au clic

5. Hero mobile :
Sur écran <= 768px :
- layout en 1 colonne
- titre NIKA HOTEL plus petit :
  font-size entre 56px et 72px, pas plus
- texte max-width 100%
- boutons en colonne ou pleine largeur
- booking card sous le texte
- booking card width 100%
- supprimer les grands décalages
- min-height raisonnable, pas énorme

6. Cards mobile :
Toutes les cartes doivent être :
width: 100%
max-width: 100%
grid-template-columns: 1fr

7. Rooms mobile :
- une chambre par ligne
- image en haut
- texte en dessous
- boutons pleine largeur
- mini galerie scroll horizontal si besoin, mais sans overflow page

8. Restaurant / Bar mobile :
- cartes empilées
- images bien cadrées object-fit cover
- aucun texte derrière la navbar

9. Contact mobile :
- coordonnées, map, formulaire doivent être empilés en 1 colonne
- Google Map width 100%
- formulaire inputs width 100%
- boutons width 100%

10. Corriger toutes les sections :
- page accueil
- /rooms
- /restaurant
- /bar
- /gallery
- /contact
- /booking

11. Ajouter des media queries propres :
@media (max-width: 1024px)
@media (max-width: 768px)
@media (max-width: 480px)
