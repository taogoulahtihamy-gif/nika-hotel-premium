CORRECTION NOTIFICATION CENTER NIKA HOTEL

Problème :
Le centre de notifications est actuellement rendu dans la sidebar.
Il s'ouvre à l'intérieur du menu gauche et coupe l'interface.

Objectif :
Transformer le centre de notifications en vrai dropdown flottant premium.

À faire :

1. Retirer complètement le dropdown du flux de la sidebar.

2. Utiliser :
position: fixed

ou

position: absolute

avec portail React.

3. Le panneau doit apparaître :

Desktop :
- sous la cloche
- aligné à droite
- largeur 380px
- hauteur max 500px
- scroll interne

Mobile :
- drawer plein écran
ou
- bottom sheet premium

4. Ajouter :

Titre :
Notifications

Sous-titre :
Historique des événements

5. Afficher :

- icône
- titre
- chambre
- heure
- statut lu/non lu

6. Cartes premium :

Nouvelle commande
Changement statut
Nouvelle réservation
Nouveau message

7. Animation :

opacity
translateY
200ms

8. Z-index :

9999

9. Le panneau ne doit jamais :
- déplacer la sidebar
- pousser le contenu
- chevaucher la navigation

10. Garder :

- badge rouge
- compteur
- Tout lu
- Vider
- son
- vibration
- historique

Résultat attendu :

Quand je clique sur la cloche :

une vraie fenêtre premium flottante apparaît au-dessus de la page comme Stripe, Notion ou Slack.

Aucun élément du menu admin ne doit être recouvert.
